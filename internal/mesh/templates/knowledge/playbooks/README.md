# Playbooks

Repeatable procedures and decision frameworks — the "how we do X" this agent
reaches for again and again. One file per playbook (`kebab-title.md`).

A playbook is not a decision (that's `decisions/`) and not a one-off finding
(that's `experience/`). It is a reusable recipe: steps, inputs, checks, pitfalls.

Examples: a release/runbook procedure, a triage decision tree, a review checklist,
a standard investigation sequence. Promote a `candidates/` learning here once it
has proven repeatable.
