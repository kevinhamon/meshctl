# Experience

Retrospectives and recurring failure modes — what this agent learned the hard
way. One file per lesson (`kebab-title.md`).

Capture: what happened, the root cause, and the durable takeaway (so the next
occurrence is recognized fast). Distinct from Playbooks (reusable procedure) and
Decisions (a ratified choice). A fresh agent legitimately has none yet.

Examples: "why the X migration stalled", "the Y gotcha that keeps recurring",
"symptoms that mean Z". Recurring lessons that harden into a procedure graduate
to `playbooks/`.
